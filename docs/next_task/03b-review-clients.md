# 03B 商品评价与晒单：小程序与管理端页面

前置：[03A](03a-review-server.md) 的数据库、接口、文件权限和 Swagger 已完成。本任务遵循其业务规则，不在前端自行虚构评价数据或资格。

## 执行提示词

阅读 README 公共约束、03A 以及相关 miniapp/admin-web Skill，直接完成下面页面与真实接口联调。

### 小程序

1. `pages/order/detail.vue` 按订单明细提供“评价 / 查看评价 / 不可评价原因”，消费 `can_review/review_id/review_status`。`OrderGoodsList.vue` 可增加有类型的操作 slot，保持结算/订单其他调用方兼容，不让基础展示组件自己请求接口。
2. 订单列表可提供“去评价”入口进入订单详情选择明细。个人中心新增“我的评价”服务入口。第一版保留既有“已完成”订单 Tab，不把它错误改为“待评价”；若以后要待评价 Tab，需单独服务端筛选和分页契约。
3. 新增 `pages/review/create.vue`、`pages/review/mine.vue`、`pages/review/detail.vue`、`pages/review/product.vue` 并注册路由。路由只传 ID，服务端核对归属；首次打开先拉资格和快照。
4. 发表页展示购买快照，星级、正文、匿名选择、最多 6 张图片。图片选择/预览可借鉴售后页面，但只调用 review 上传接口；每张显示上传中/成功/失败，支持删除和单张重试。
5. 上传未完成不能提交；只提交已上传 file_id，不提交本地路径。删除一张本地附件不等于自动删除服务端公共文件；离开页面提示未保存内容，不跨账号存储评价草稿。
6. 点击提交只生成一次 request_id；超时后保持原载荷和 request_id 重试/查询结果。内容变更与幂等规则一致，避免重复评价。响应丢失不能显示“已成功”或重新生成 request_id 盲重发。
7. 成功页显示“评价已提交，待审核”，不能立即在公开商品页插入一条假公开评价。我的评价展示待审核/已公开/驳回/隐藏及原因，第一版无修改、追评和删除按钮。
8. 商品详情新增评价摘要与少量公开评价预览、全部评价入口。使用 `ReviewCard` / `RatingStars` 等小组件，图片可预览；空、失败、加载状态独立，不让评价接口失败导致商品无法购买。
9. 公开列表展示真实总数、平均星级、有图筛选与分页；隐藏/匿名行为按契约，不使用本地数组过滤冒充服务端总数。切筛选时防旧请求覆盖新列表。

### 管理端

1. 新增 `src/modules/product/review/`：普通 Ant Design Table 查询页 + 详情 Drawer。按商品、状态、星级、有图、时间筛选，服务端分页，复用已有 ContentCard/PageHeader。
2. 展示订单关联、会员信息、商品快照、评分、正文、图片和审核记录；只有有权限的管理员能看非公开内容，不使用公众 API 绕过后台权限。
3. 待审核可通过/驳回（必填原因）；公开可隐藏、隐藏可恢复；商家回复按 03A 契约。提交时携带期望状态，并对状态变化冲突刷新提示，防双击。
4. 菜单、路由、按钮、默认授权落地页同时接入现有权限体系；无权限不能仅靠隐藏按钮。读取 `framework/router/authorized-pages.ts`，防止“只有评价管理权限”的账号被错误送至无权限页。
5. 使用生成 API Client。按 admin-web Skill 通过公共 HTTP 响应处理错误，失败保留表单，不伪造保存成功。

### 验收

- 两条订单明细可各评一次；已评不能再次发表；其他人的 order_item_id 无法访问/提交。
- 拒绝相册权限、上传慢/失败/删图、超时重试、切换账号、页面返回均有明确状态。
- 提交 → 我的评价待审核 → 后台通过 → 商品页展示 → 后台隐藏 → 商品页及统计消失完整联调。
- 匿名公开展示不泄漏身份；驳回理由仅按授权展示；不包含评价返利营销功能。
- 后台无权限/仅 list/审核权限分级验证，筛选分页和审核后列表刷新正确。
- 对真实组件/状态函数补回归，执行 README 两个前端的检查；记录微信真机和真实文件存储的验证情况。
