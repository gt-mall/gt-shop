# 06 骨架屏与弱网状态交互

## 当前基础与具体缺口

- `src/services/request.ts` 已有统一 HTTP/业务错误、默认 15 秒 timeout、认证失效会话归属检查；不要重写请求层。
- Cart Store 已有 loading/error、旧数据保留和序号保护；CartDrawer 已有状态 UI、共享写锁、滚动锁和源码测试。
- `pages/my/index.vue` 在触底时先递增 productPage，加载失败未退回，下一次可能跳过一页；推荐刷新/加载更多也缺完整查询版本隔离。
- 分类页已有 moreError 和失败回退，但加载中切换条件的请求处理仍需检查，不能简单把旧页模板复制过去。
- 商品/订单/地址页有 loading 或空态，未发现通用 Skeleton；`components/ProductCard.vue` 有 imageFailed，需检查图片 URL 更新后是否复位。

## 执行提示词

先读取 README，主要完善小程序呈现和异步状态，不引入离线数据库、Service Worker、全局写请求自动重放系统。

### 第一阶段：轻量公共组件

1. 新增可复用 `Skeleton.vue`（行/矩形/圆形、宽高、圆角、动画开关）及必要的 `PageState.vue`（loading/empty/error、文案、重试事件）。组件只展示，不自己发业务请求。
2. 首屏骨架布局匹配真实内容尺寸，避免一加载就跳动；快速响应可延迟约 150ms 才展示骨架，但不能人为延迟成功数据。H5 支持减少动效偏好，其他端提供关闭闪烁的选项。
3. 商品卡片/详情、订单卡片、购物车和地址列表按需要组合骨架；不为每页创建一套相同样式，也不把整个页面逻辑塞进通用状态组件。
4. 增加网络状态 composable/service，复用 `uni.getNetworkType/onNetworkStatusChange`，只注册需要的监听并正确取消。网络类型仅是提示：wifi/4g 不等于 API 可用，unknown 不等于离线。

### 第二阶段：页面接入与弱网修复

1. 第一批覆盖首页、分类、商品详情、个人中心推荐、购物车页面/抽屉、订单列表/详情、收货地址；结算页重点保障价格/运费预览的加载及失效状态。04/03B 若已完成，同步接入搜索/评价；尚未完成不提前造空页面。
2. 首次无数据：骨架 → 成功/真实空态/失败。已有数据刷新：保留内容并显示轻量刷新提示；失败保留内容并可重试，不清空成“暂无”。分页失败保留旧列表，列表尾部重试当前页。
3. 统一每类查询的序号/版本快照，捕获参数与账号；旧请求不得覆盖新搜索词、分类、地址、账号或新商品。页码仅在成功后提交，返回结果按稳定 ID 去重。
4. 先修复个人中心推荐跳页及刷新/加载更多交叉问题，再检查首页、分类和订单同类逻辑；使用真实业务 API 的 total/分页约定判断无更多。
5. 图片加载失败用占位图；URL/商品切换时清理 imageFailed，使新图能重新加载。不要重复自动请求同一坏图造成循环。
6. 断网提供轻提示与手动重试；恢复网络时只对当前可见页面做合并后的只读刷新，避免所有隐藏 Tab、多个组件同时请求。同一时间只允许一个刷新，无限重试禁止。
7. 写操作防双击；下单/支付/取消/地址保存/评价提交不因“网络恢复”自动重放。超时可能意味着服务端已成功，保留已有幂等请求 ID 并查询状态/给明确重试入口，不声称失败就重新创建业务单。
8. 结算金额/运费/库存预览失败或正在切换地址时禁用提交；旧商品列表可浏览不代表旧价格可成交。复用后端重新计算，不在离线时生成假订单。
9. 401 仍由现有请求层处理，不能把它当普通弱网一直重试；退出清理会员数据，隐藏/卸载停止计时器、监听、重试任务，保持 CartDrawer 的滚动锁恢复。
10. API 错误只在恰当的交互边界提示一次；不一层层重复 toast、不显示底层堆栈。前端尽量不用 try/catch，但必须保证 Promise 错误被处理、Loading 复位。

## 验收

用可控制的请求延迟和失败注入验证实际源码/组件，至少覆盖：

- 首次加载 3 秒、成功空列表、HTTP 500、断网/恢复、超时、认证失效。
- 推荐第 2 页失败后重试仍为第 2 页，之后第 3 页不重复；旧第 2 页不能混进新刷新列表。
- 查询 A 慢/B 快、切地址预览乱序、账号切换，旧响应全部被忽略。
- 关闭抽屉/离开页面后请求返回，不复活页面、不残留遮罩/滚动锁。
- 已有内容刷新失败不消失；初次失败不显示“暂无”；失效图片换 URL 后能恢复。
- 结算/写操作在弱网下无重复业务单，无旧金额误提交，恢复网络不自动付款。
- 记录 H5 模拟弱网、微信开发者工具与真机结果；执行 README 小程序检查，公共组件附接入说明。

官方资料：[UniApp 网络状态 API](https://uniapp.dcloud.net.cn/api/system/network.html)。监听须与取消监听配套，网络提示不能替代接口真实结果。
