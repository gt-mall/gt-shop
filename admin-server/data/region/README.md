# 中国省/市/区县三级行政区划数据

本项目在 `admin-server/data/region/regions.json` 中内置了中国大陆省、市、区县三级行政区划数据，用于地址选择、运费模板匹配及地区解析。

## 数据信息

- **数据来源**：中华人民共和国国家统计局《统计用区划代码和城乡划分代码》（依据《关于统计上划分城乡的规定》及《统计用区划代码和城乡划分代码编制规则》）
- **原项目地址**：[modood/Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)
- **数据版本**：2023年统计用区划代码和城乡划分代码（截止时间：2023-06-30，发布时间：2023-09-11）
- **数据更新时间**：2023-09-11（编码标准化及内嵌构建时间：2026-09）
- **License**：WTFPL (Do What The Fuck You Want To Public License)

## 使用规范与约束

1. **三级行政区划**：
   - 本项目只使用省、市、区县三级联动数据（不包含乡镇、街道、村庄五级数据）。
   - 直筒子市（如东莞市、中山市、儋州市、嘉峪关市）直接下辖街道/镇，在三级选择器中保持作为第三级节点使用。
2. **编码标准**：
   - 行政区划 `code` 统一为 `string` 类型，禁止使用数值类型。
   - 省级编码统一补齐为标准 6 位（如山东省 `370000`）。
   - 市级编码统一补齐为标准 6 位（如济南市 `370100`）。
   - 县区编码保持对应 6 位/9 位行政区划编码（如历下区 `370102`）。
3. **编译与运行**：
   - 本数据通过 `data/embed.go` 的 `//go:embed *` 直接编译进 Go 可执行文件。
   - 服务启动时由 `internal/region.Service` 一次性解析至内存并建立索引。
   - **运行时禁止联网获取行政区划数据**，无需访问磁盘与外部网络。
